DwgExportPro

DwgExportPro - batch DWG plotting / export tool

About this tool

DwgExportPro is a batch-processing utility for AutoCAD that opens a list of drawing files and exports each one to PDF or PNG automatically, with per-file layout selection, logging, reusable project files and automatic recovery/restart if AutoCAD becomes unresponsive.

This tool is built on top of the original ScriptPro batch-processing engine released by Autodesk Developer Network, rewritten and extended with a dedicated PDF/PNG export workflow, per-drawing layout picking, and a more robust AutoCAD COM automation layer.

System Requirements

Tested with AutoCAD 2021 onwards (64-bit). The application will use the version of AutoCAD most recently used on the system, unless a specific AutoCAD executable path is set in Options.

Requires .NET Framework (see project target) and a licensed, installed copy of AutoCAD on the machine running the tool.

Installation

Copy the contents of the build output folder (the main application file, DwgExportPro.exe, and its supporting DLLs, e.g. DrawingListUC.dll) to the same location on your local system.

Usage

DwgExportPro is a batch-processing tool that opens each drawing in a list and exports it to PDF or PNG. Before you begin, decide which drawings you want to process and which layout (or Model) should be plotted for each.

In the DwgExportPro Project Editor, you add the drawings, choose a layout per drawing, choose the export format (PDF or PNG), and save this as a DwgExportPro project file (.bpl).

While running a project, DwgExportPro opens each drawing in sequence, plots it to the selected format, and closes it before moving to the next file.

Starting DwgExportPro

DwgExportPro is a stand-alone application that runs independently of AutoCAD. Create a shortcut to DwgExportPro.exe on your desktop, or run the executable directly from Windows Explorer or a command-prompt window.

DwgExportPro has a ribbon UI with the following groups: List, Drawing Files, Run, Stop, Options and Help.

List:

  • New - Creates a new DwgExportPro project.

  • Load - Loads an existing DwgExportPro project.

  • Save - Saves the current DwgExportPro project.

  • Save As - Saves the current project to another location.

  • Load SCP Project

    • Reads a legacy ScriptPro (.scp) project file, for migration purposes.

Drawing Files:

Add - Adds drawing files (DWG & DXF) to the current project. Add From Folder - Adds drawing files (DWG & DXF) from a selected folder. Remove - Removes the selected files from the current project. Check/Uncheck - Allows drawing files to be skipped during processing.

Run:

  • Checked - Exports all the checked drawing files in the current project.
  • Selected - Exports all the selected drawing files in the current project.
  • Failed - Re-runs export on all drawing files which previously failed.

Stop:

  • Stop - Stops the current batch export.

  • Options:

    • Settings - Shows the Options dialog, which lets you set the time-out period, log file path and initial startup script.

Help:

  • Help - Shows this ReadMe file, if placed in the same folder as DwgExportPro.exe or the parent folder.

The Options dialog contains a number of project-related settings:

Process timeout per drawing in seconds

How long AutoCAD can be inactive before DwgExportPro aborts processing on the current drawing and moves on to the next one. Increase this for very large drawings.

Restart AutoCAD after _ drawings

Number of drawings to process before restarting AutoCAD, to reset memory usage during long batch runs.

AutoCAD startup script file

A script executed once when a new AutoCAD session starts (e.g. to load required LISP/.NET applications).

Process log folder

Location where logs are created, named DEPlog_date_hour_min_sec.log plus a matching DEPlog_Detail_... file containing AutoCAD's command-line output for each drawing.

Create image before closing the drawing file

Captures a screenshot of the AutoCAD window, for all processed drawings or only failed ones.

Select DWG/DXF files in sub directories

Makes Add From Folder search sub-folders when populating the drawing list.

Run the tool in diagnostic mode

Pauses just before closing each drawing so you can verify its state. No timeout applies in this mode.

Delay during process (Seconds)

Slows down the tool, giving AutoCAD more time to respond to commands.

AutoCAD exe path to use

Selects a specific AutoCAD version/variant to use. If empty, the most recently used AutoCAD on the system is used.

Command Line Access

To run a DwgExportPro project from a batch file:

DwgExportPro.exe <project name> run

Example: C:\DwgExportPro\DwgExportPro.exe C:\TestProject.bpl run

Add exit at the end to close DwgExportPro silently after processing:

C:\DwgExportPro\DwgExportPro.exe C:\TestProject.bpl run exit

Uninstallation

From Control Panel, find DwgExportPro and uninstall, or simply delete the installation folder if it was installed as a portable app.

Credits

DwgExportPro is based on ScriptPro 2.0, originally released by Autodesk Developer Network (written by Virupaksha Aithal, with input from Kean Walmsley). The original batch-processing engine, scripting model and ribbon UI concept come from that project; the PDF/PNG export pipeline, layout picker, and AutoCAD COM reliability fixes in this build are custom additions.
